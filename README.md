This project demonstrates a **recommendation system** built using **pure Python**, analyzing user and page data to suggest pages a user may like.  
No external machine learning libraries were used; the logic is implemented from scratch.  

---

## 📌 Project Overview  
- Input datasets: `data.json`, `data_2.json`, `massive_data.json`.  
- Performs data cleaning and preprocessing in **Python**.  
- Implements a simple recommendation algorithm based on user interactions and relationships.  
- Outputs a list of suggested pages for each user.  

---

## 🛠 Tech Stack  
- Python (no external ML libraries)  
- JSON for input/output data handling
